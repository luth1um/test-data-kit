# Test-Data Kit
This library contains generators for test data requiring checksums and/or specific formats (e.g., IBAN).
The generated data satisfies properties that can be validated offline (like checksums, length, format, etc.).
Apart from that, the data is generated randomly, such that overlaps with real-world data is purely coincidental.
For other test data like names and animals, tools like [Faker](https://fakerjs.dev) might be helpful for you.

By using WebAssembly as one of the targets, this library is available for Rust as well as JavaScript/TypeScript.

## Available Functions for JavaScript and TypeScript

This project consists of Rust code being compiled with `wasm-pack` to WebAssembly.
The glue code for JavaScript and TypeScript is generated by using `wasm_bindgen`.
The following functions are exported by the wasm binary.

| Function | Description |
|---------------------------------------------|---------------------------------------------------|
| `randomIban(country: IBAN_COUNTRY): string` | Generates a random IBAN for the specified country |

## 🦀 Developing the Tool

In case you want to contribute to the tool or fork the repository, only few steps are necessary:
- You need to install _wasm-pack_ with `cargo install wasm-pack` for WebAssembly outputs.
- The WebAssembly binary (including glue code for JavaScript/TypeScript and an NPM package) is generated by running `wasm-pack build --target bundler`.
- For further information on compiling Rust to WebAssembly, see the [MDN Web Docs](https://developer.mozilla.org/en-US/docs/WebAssembly/Rust_to_Wasm).
